Creature life and survival

Gameplay

The core loop of a survival game: grow up, eat, drink, stay healthy and breed.

What it does
  • Four growth stages (Child, Juvenile, Adult, Elder), each with its own stats, and the model scales smoothly as you grow.
  • Hunger, thirst, stamina, oxygen and body temperature, driven by season, region, altitude and time of day.
  • Sickness from rotten meat, injuries per body part, and bleeding that stacks.
  • Eggs that hatch after 3 minutes. Spawning at your pack nest, your saved spot or a safe random point.
  • Growth boosts for playtime (x1.5 after 20 minutes, x2 after an hour) and for sleeping at night.
The hard part

Rescaling a moving character on the server snaps it backwards on the player's screen. Growth now waits until the dino stands still, so nobody rubber-bands. Saved spawns are checked for terrain, water and solid ground before use, so nobody spawns inside a cliff.

  • Growth stages
  • Vitals
  • Status effects
  • Spawning

Combat

Gameplay

Server-side combat for creatures from raptor size to kaiju size.

What it does
  • Bites and area attacks that hit from a hitbox fitted to each creature's jaws.
  • Bleeding, injuries and an in-combat timer with a countdown on the HUD.
  • Grabbing and carrying other players or objects while you keep moving.
  • Combat logging is punished, so nobody escapes a fight by leaving the game.
  • Roars that ping your position to nearby players.
The hard part

Every hit is decided on the server, never by the client. A huge dino has to be able to hit a small one right in front of it, so each hitbox is fitted to its rig all the way down to the ground.

  • Server hit checks
  • Status effects
  • Anti combat-log

Movement and procedural animation

Gameplay

Custom movement that makes big animals feel heavy and small ones feel quick.

What it does
  • A custom controller with body tilt over terrain. Turn speed comes from each creature's real body length.
  • Head look that turns the neck toward where you're looking, on 48 different rigs.
  • Tail physics that swing when you turn, plus leg IK.
  • Flying: takeoff, climbing, diving, hover braking and landing found by raycast.
  • Swimming in the sea, rivers and lakes, with breaching jumps, splashes and an underwater camera filter.
  • A sprint camera zoom, and a first-person view that looks out of the real head.
The hard part

Every rig is built differently, so the neck chain is found automatically and measured from the rig's rest pose instead of its animated pose, which made heads twitch. The server's growth rescale rewrites joints every second, so the script spots joint changes it didn't make and treats them as the new base.

  • Motor6D
  • CFrame math
  • Raycasting
  • IK

Saves and player data

Data and money

Saves that don't lose progress or duplicate items.

What it does
  • ProfileStore saves with session locking, so two servers can never write the same save.
  • A save throttle: at most one write per player every 15 seconds, with a trailing save so nothing is dropped.
  • A save slot for each creature, plus settings, profiles, redeemed codes and HUD layouts.
  • Every setting a client sends is checked against a whitelist on the server.
  • Saves on shutdown, so updates and server restarts don't wipe progress.
The hard part

Quest progress saved on every single bite and sip, which hit Roblox's DataStore write limit on live servers. The throttle fixed it inside the save module, without touching any of the code that calls it.

  • ProfileStore
  • UpdateAsync
  • Session locks
  • Throttling

Weather and seasons

World and AI

Weather that changes how you play, not just how the sky looks.

What it does
  • Four seasons that change the temperature and where herds migrate.
  • Storms that flood the sea, droughts that drain it and brown the grass, and blizzards with whiteouts and settling snow.

Claims a player's save with a lease token inside UpdateAsync, so two servers can never write the same save. It refuses corrupt data and saves from a newer version, and fills in missing fields.

src/server/Data.luauLines 64–101
local function claim(key: string, force: boolean)
	if not store then
		return "error", "no DataStore access"
	end
	local status, result
	local ok, err = pcall(function()
		store:UpdateAsync(key, function(old)
			status, result = nil, nil
			if old ~= nil and type(old) ~= "table" then
				status = "corrupt"
				return nil
			end
			old = old or {}
			if (old.Schema or 0) > SCHEMA then
				status = "newer"
				return nil
			end
			local s = old.Session
			if not force and s and s.Token ~= TOKEN and (s.Expires or 0) > os.time() then
				status = "locked"
				return nil
			end
			old.Schema = SCHEMA
			old.Data = reconcile(old.Data)
			old.Meta = old.Meta or {}
			old.Meta.Receipts = old.Meta.Receipts or {}
			old.Meta.Order = old.Meta.Order or {}
			old.Session = { Token = TOKEN, Expires = os.time() + LEASE }
			status = "ready"
			result = old
			return old
		end)
	end)
	if not ok then
		return "error", err
	end
	return status, result
end

The client only presses a prompt. The server checks everything else: who owns the machine, locks, free space, distance, and that the save still has that machine on that pad.

local function onPrompt(prompt: ProximityPrompt, thief: Player)
	if prompt.Name ~= "Steal" then
		return
	end
	local model = prompt.Parent and prompt.Parent.Parent
	if not model or not model:IsA("Model") then
		return
	end
	local victim = Bases.ownerOfModel(model)
	if not victim or victim == thief or not Bases.state[thief] or not Bases.state[victim] then
		return
	end
	if carries[thief] or model:GetAttribute("CarriedBy") or model:GetAttribute("Landing") then
		return
	end
	if Bases.isLocked(victim) then
		Bases.notify(thief, "That base is locked!", "bad")
		return
	end
	if not Bases.freePad(thief) then
		Bases.notify(thief, "Your base is full, no room for it!", "bad")
		return
	end
	local hrp = aliveRoot(thief)
	local root = model.PrimaryPart
	if not hrp or (hrp.Position - root.Position).Magnitude > 16 then
		return
	end
	local pad = model:GetAttribute("Pad")
	local vd = Data.get(victim)
	local entry = vd and vd.Machines[tostring(pad)]
	if not entry or entry.Id ~= model:GetAttribute("MachineId") then
		return
	end

A slap with a server cooldown and a server-picked target: the nearest player in range and in front of you. Hitting a thief sends their stolen machine home.

local function slap(player, tool)
	if lastSlap[player] and os.clock() - lastSlap[player] < Config.SlapCooldown then
		return
	end
	lastSlap[player] = os.clock()
	local hrp = aliveRoot(player)
	if not hrp then
		return
	end
	local handle = tool:FindFirstChild("Handle")
	if handle and handle:FindFirstChild("Whoosh") then
		handle.Whoosh:Play()
	end
	local best, bestDist
	for _, other in Players:GetPlayers() do
		if other ~= player then
			local ohrp = aliveRoot(other)
			if ohrp then
				local offset = ohrp.Position - hrp.Position
				local dist = offset.Magnitude
				if dist <= Config.SlapRange and dist > 0 and hrp.CFrame.LookVector:Dot(offset.Unit) > 0.3 and (not bestDist or dist < bestDist) then
					best, bestDist = other, dist
				end
			end
		end
	end
	if not best then
		return
	end
	local ohrp = aliveRoot(best)
	local dir = (ohrp.Position - hrp.Position) * Vector3.new(1, 0, 1)
	dir = if dir.Magnitude > 0 then dir.Unit else hrp.CFrame.LookVector
	Remotes.Knockback:FireClient(best, dir * 75 + Vector3.new(0, 40, 0))
	if handle and handle:FindFirstChild("Smack") then
		handle.Smack:Play()
	end
	if carries[best] then
		local c = carries[best]
		returnMachine(best, "You slapped " .. best.DisplayName .. " and got your machine back!")
		Bases.notify(best, "Slapped! The " .. Config.ById[c.Id].Name .. " went back home.", "bad")
	end
end
